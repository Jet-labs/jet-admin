Enhancing the Data Table Widget

Select your preferred interaction patterns for the new advanced Table features.

1. Row Editing & Column Selectivity

How should inline row editing look and operate?

A

Row-by-Row Inline Edit

An "Edit" button on each row. Clicking it turns that row's selected editable cells into inputs, with "Save" and "Cancel" buttons. Runs the Save workflow for that row.

B

Bulk Excel-Style Edit

Double-click any editable cell to edit immediately. Changes are staged with a subtle yellow highlight. A global "Save Changes" bar at the bottom triggers the bulk edit workflow.

2. Search & Export Controls

Where and how should the Search Box and Export buttons be positioned?

C

Integrated Widget Header

Placed in the table header: Search input on the left, Export/Action buttons on the right. Feels like a unified professional data grid.

D

Separate Configuration Toolbar

A floating toolbar right above the table. Highly customizable, allows toggling search visibility, exporting to CSV/Excel, and adding custom action buttons.

3. Multiple Row Selection & Bulk Actions

How should multiple selection operations (like bulk delete or bulk export) behave?

E

Floating Bulk Actions Bar

Selecting multiple checkboxes slides up a sleek floating action bar at the bottom: "Selected X rows: [Delete] [Export]". Highly visible and saves space.

F

Header Action Dropdowns

Standard checkboxes on rows, with a dedicated "Bulk Actions" dropdown menu appearing in the table header only when one or more rows are selected.
