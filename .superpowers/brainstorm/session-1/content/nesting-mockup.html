Option A: Flex-Grid Hybrid (Sections with Grid Canvas)

The canvas consists of a vertical list of Sections (or Containers). Inside each section, you have a grid layout (e.g., 12 columns) where you can drag-and-drop widgets. The section height auto-grows based on its contents, preventing overflow. Moving sections is a simple vertical sort.

Option B: Pure Nestable Flex Stacks (Flexbox rows/cols)

No grid columns at all. The canvas is built of nestable boxes that align their children either vertically (V-Stack/Column) or horizontally (H-Stack/Row) using CSS Flexbox rules. Dragging a widget inserts it into the sequence of children in a box.
