A

ToolJet Grid (Absolute Grid with Nestable Containers)

Every component is absolute-positioned using coordinates (x, y, w, h). To group components or create layouts, developers use Container widgets. A Container is placed like any normal widget but contains its own nested grid canvas. Responsiveness is handled via desktop/mobile toggles (re-positioning or hiding components per device viewport).

B

Retool Layout (Hybrid Flow Grid)

Retool mixes absolute coordinates with a horizontal grid-column structure (usually 12 columns). Instead of absolute heights (h), height is often fluid and auto-grows based on component content (e.g., table with varying rows, expandable forms). Sections stack vertically, and elements wrap dynamically on smaller screens without separate mobile configurations.
