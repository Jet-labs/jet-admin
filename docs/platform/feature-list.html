Feature Inventory

This is the honest, code-derived inventory of what Jet Admin does today. It is grouped by module and uses the following maturity labels:

LabelMeaning
StablePrimary code path, exposed in the UI/API, expected to work in normal operation
BetaShipped but still evolving; validate in your deployment before relying on it
ExperimentalCode exists but is opt-in, narrowly scoped, or not recommended for critical flows
InternalService/config primitive with no first-class UI
Not implementedNo code path exists today; listed to prevent assumptions

Maturity is not a security rating. See Limitations for operational and security caveats.

Explicitly absent or partial​

These are commonly assumed but do not exist as first-class features:

  • Application export/import and application bundles.
  • Server-side application/page state shared across users.
  • Release traffic splitting, staged rollout, or automatic rollback.
  • Asset-version or release retention policies.
  • HMAC signature verification for third-party webhooks.
  • A generic notification rules engine.
  • A query result cache or query cancellation route.
  • Per-folder ACLs or recursive folder filtering.
  • Widget plugin loading at runtime.
  • Read-only SQL enforcement independent of credentials.
  • Built-in platform metrics/tracing.
  • Any tenant-level marketplace publishing UI.

For the operational consequences, read Limitations.
